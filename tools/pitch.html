🎵 소리 분석기 (음정·타이밍 기록)

PC에서 나오는 소리(유튜브 탭 등)나 오디오 파일을 받아서, 소리가 날 때마다 시각 · 음정(Hz/음이름) · 배음 · 크기 · 잔향 길이를 기록하고 텍스트로 정리합니다. 결과 텍스트를 복사해서 Claude에게 붙여 넣으면 됩니다.

  1. 탭 소리 캡처를 누르고, 공유 창에서 유튜브가 열린 Chrome 탭을 고른 뒤 아래쪽 「탭 오디오도 공유」를 켜고 공유합니다.
  2. ● 기록 시작 → 영상에서 원하는 부분(예: 17초)을 재생 → ■ 기록 정지.
  3. 아래 결과 텍스트를 복사해서 붙여 넣기. (파일이 있으면 오디오 파일 열기로 바로 분석해도 됩니다.)
